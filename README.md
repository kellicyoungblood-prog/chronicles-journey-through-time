# CHRONICLES: A Journey Through Time

Expedition 001 — The Missing Record. Ancient Thebes, circa 1250 BCE.

Version 3 is a buildless HTML/CSS/JavaScript experience for GitHub Pages. Open index.html with its accompanying files, or serve this directory with any static web server. No API keys, packages, database, or build step are required.

## Features
- Cinematic marketplace and Scribe’s Workshop, each with three keyboard-accessible hotspots.
- Research-based exhibit explanations and museum/university source links.
- Browser-local field journal, reflection, text download, and restart control.
- Two-step investigation with retry feedback and a conclusion about evidentiary limits.
- Responsive layout and native modal dialogs.

## Publish with GitHub’s website
1. Unzip CHRONICLES_Expedition_001_v3.zip on your computer.
2. Open the repository: https://github.com/kellicyoungblood-prog/chronicles-journey-through-time
3. At the repository’s main file list, select Add file → Upload files.
4. Drag index.html, styles.css, app.js, README.md, and the entire assets folder from the extracted folder into the upload area. Upload the contents, not the outer CHRONICLES_Expedition_001_v3 folder or the ZIP itself. Keep the assets folder structure.
5. Verify that index.html is at the repository root and both images are under assets/.
6. Enter a commit message, such as “Add Version 3 cinematic marketplace and Scribe’s Workshop.” Commit directly to the existing publishing branch (normally main).
7. Open Actions and wait for the Pages build/deployment to finish. If needed, Settings → Pages shows the existing publishing configuration; retain it.
8. Open https://kellicyoungblood-prog.github.io/chronicles-journey-through-time/ and refresh. If the old version remains, hard-refresh with Command+Shift+R on Mac.
9. Check three marketplace exhibits, three workshop objects, journal saving, and the investigation. Confirm the footer says Version 3.

Git history preserves the prior version. To undo, restore index.html from the preceding commit; the new unreferenced assets can remain.

## Historical boundaries
The mission, accounts, sack quantities, layouts, and time travel are fictional. The artwork is AI-created interpretation, not an archaeological reconstruction; architectural details, dress, and goods still need specialist review before a museum-quality claim is appropriate. Practice accounts are English-language learning aids, not translations or facsimiles.

The Met Ramesside account dates approximately 1300–1080 BCE. Museo Egizio Suppl. 6365 dates 1190–1077 BCE and is explicitly identified as a later comparison. Nebamun is an earlier New Kingdom comparison. No museum endorsement is implied and no museum object photography is reproduced.

Source links and contextual notes appear in the experience’s Sources & context dialog. Sources checked November 12, 2026.
